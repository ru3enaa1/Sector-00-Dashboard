# Capturas

Las imágenes que ilustran el `README.md` de este repositorio.

## Cómo nombrarlas

`NN-apartado.png`, con dos dígitos, en minúsculas y sin tildes ni espacios.
El número fija el orden en que aparecen en el README.

```
01-hangar.png
02-consola.png
03-carta-epica.png
```

Los espacios en un nombre de archivo obligan a escribir `%20` en el enlace de
Markdown, y basta que uno se escape para que la imagen no cargue. Los guiones
lo evitan.

## Cómo tomarlas

| | |
|---|---|
| **Ancho** | El mismo en todas. 1440 px va bien: se lee en un móvil y no obliga a GitHub a reducirla tanto que se pierda el texto. |
| **Idioma** | **Uno solo para toda la serie.** El tablero habla inglés y español; mezclarlos hace que el README parezca de dos productos. El inglés es la puerta si esto lo abre alguien de fuera. |
| **Datos** | **Proyectos y wallets de ejemplo, nunca tu lista real.** Una captura publica lo que salga en ella: nombres de proyectos que sigues, direcciones, importes y tu propio criterio de tier. Eso es exactamente la ventaja que el tablero existe para guardar. |
| **Encuadre** | Sin la barra del navegador ni la del sistema. Lo que interesa es la aplicación. |
| **Escena** | A pantalla completa, para que el hangar se vea entero. La escena está pensada para llenar la pantalla; una ventana estrecha la recorta por donde no debe. |
| **Peso** | Menos de 500 KB cada una. Un README con 12 capturas de 3 MB tarda en abrir y engorda el repositorio para siempre. |

## Qué se necesita

Marcadas con ★ las que más cuentan si hay que elegir pocas. Los nombres son los
que el `README.md` ya tiene escritos: si usas otro, hay que cambiar el enlace.

**La escena**
- ★ `01-hangar.png` — el hangar entero, ocho islas, con el mecánico junto a una
- ★ `03-carta-epica.png` — la carta girada, en su arte épico. Es el momento que define el producto
- `02-consola.png` — la consola de `Ctrl+K` con algo escrito
- `12-placa-operador.png` — la placa del operador, o el cassette abierto

**Las islas**
- ★ `04-race-strip.png` — RACE STRIP en **EN PISTA**, con varias cuentas atrás vivas
- ★ `07-farm-rig.png` — FARM RIG con los tres colores del semáforo a la vez. Sin las tres luces no se entiende la isla
- ★ `08-showroom.png` — SHOWROOM con una tarjeta de resultado, mejor si es en verde y hay otra en rojo
- `05-race-strip-archivo.png` — la vista **ARCHIVO**, con algún descarte y su motivo
- `06-key-vault.png` — KEY VAULT con una wallet que tenga varias llaves del mismo proyecto
- `09-salvage-market.png` — SALVAGE MARKET, idealmente con la franja de peligro encendida
- `10-workshop.png` — WORKSHOP con varios cajones y un enlace en **⛏ FARMING**
- `11-signal-array.png` — SIGNAL ARRAY con el contador de aciertos visible

## Después

Con las imágenes aquí, se acomodan en el `README.md` con su descripción. Los
huecos ya están puestos, cada uno con su comentario `<!-- NN-nombre.png -->`.

No hace falta que estén las doce: **seis bien elegidas cuentan mejor la historia
que doce a medias.** Las que sobren, se quitan del README con su hueco.
