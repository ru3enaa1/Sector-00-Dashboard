# Capturas

Aquí van las capturas de pantalla del tablero. **Deja los archivos en esta
carpeta** (`docs/capturas/`) y yo los coloco en el README con su descripción.

`docs/` está versionado, así que las capturas viajan con el repositorio. La
vitrina pública (`docs/capturas/` de la rama `vitrina`) usa los mismos nombres:
lo que caiga aquí se copia allí tal cual.

## Cómo nombrarlas

`NN-apartado.png`, dos dígitos, minúsculas, sin tildes ni espacios. El número fija
el orden en que salen en el README.

Los espacios obligan a escribir `%20` en el enlace de Markdown, y basta que uno se
escape para que la imagen no cargue. Los guiones lo evitan.

## Cómo tomarlas

| | |
|---|---|
| **Ancho** | El mismo en todas. 1440 px va bien. |
| **Idioma** | **Uno solo para toda la serie.** El tablero habla inglés y español; mezclarlos hace que el README parezca de dos productos. |
| **Datos** | **Proyectos y wallets de ejemplo, nunca tu lista real.** Una captura publica lo que salga en ella: nombres, direcciones, importes y tu propio criterio de tier. Es justo lo que el tablero existe para guardar. |
| **Encuadre** | Sin la barra del navegador ni la del sistema. |
| **Escena** | A pantalla completa: el hangar está pensado para llenarla. |
| **Peso** | Menos de 500 KB cada una. |

## Las que hacen falta

Marcadas con ★ las que más cuentan. El orden es el del relato del README: el
mundo, el juego, el criterio, y el tablero juzgándote.

**El mundo**
- ★ `01-hangar.png` — el hangar entero, las ocho islas, con el mecánico junto a una
- ★ `03-carta-epica.png` — la carta girada en su arte épico. Es el momento que define el producto
- `02-consola.png` — la consola de `Ctrl+K` con algo escrito

**El criterio — las dos más importantes, y las más nuevas**
- ★ `13-tacometro.png` — los seis controles con la aguja y **el cupo de la zona roja
  lleno**, con la lista de ocupantes a la vista. Es el filtro hecho visible, que es
  la promesa central del README
- ★ `14-marcador.png` — el veredicto de la tasa de acierto por tier, mejor si sale
  **TU TIER VA AL REVÉS**. Es el tablero contradiciéndote, y ninguna hoja de
  cálculo hace eso

**El oficio**

  las tres luces no se entiende la isla

  en rojo
- `04-race-strip.png` — EN PISTA con varias cuentas atrás vivas y la columna
  `Intensity` con cifras
